# Getting Started

This is a practise project for automation testing using Playwright with Pytest.
The website used for the practise is Rahul Shetty Academy [dummy e-commerce website](https://rahulshettyacademy.com/client).

## Prerequisites
The project uses [uv](https://docs.astral.sh/uv/), a python package and project manager. 

You can install uv directly through any your chosen IDE. 
```
pip install uv
```
